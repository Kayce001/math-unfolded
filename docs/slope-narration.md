# 斜率试点旁白稿

## 同样一分钟，谁走得更远

看，这两个人从同一起点出发，都在匀速向前走。青色每分钟走一米，红色每分钟走两米。同样一分钟，红色走得更远。

## 把运动留在图上

现在，把运动画在图上。横轴是时间，纵轴是走过的路程。随着时间增加，两个点都沿着直线向前移动。

## 直线记录变化快慢

青线每向右走一格，就向上走一格。红线每向右走一格，就向上走两格。刻度相同，红线更陡，表示同样的时间里，路程增加得更多。

## 横着走多少，竖着变多少

只看红线上的这两个点。横向增加一，纵向增加二。用纵向变化除以横向变化，二除以一，得到二。这就是红线的斜率。

## 换一个横向间隔

再把两个点拉开。横向增加二，纵向增加四。四除以二，仍然是二。间隔变了，但变化量的比值没有变。

## 带着一个问题去探索

斜率，说的是每单位横向变化，对应多少纵向变化。在刚才的路程时间图中，它的单位是米每分钟。如果把斜率从二改成一，直线会怎样？先想一想，再亲手验证。
